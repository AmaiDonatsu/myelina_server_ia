# Ejemplos de Aplicaciones Cliente — Myelina Server IA

En este directorio encontrarás ejemplos prácticos y aplicaciones completas que demuestran cómo integrar y consumir los servicios de **Myelina Server IA**:

- **[CLI Agent (examples/cli)](./cli/readme.md)**: Aplicación de terminal interactiva con detección automática de sistema operativo (Linux / Windows) y ciclo reactivo (ReAct) que permite a la IA ejecutar acciones en la computadora local mediante etiquetas `<exec>comando</exec>`.
