# Primeros pasos

Este proyecto esgtá destinado a ser un servidor de inferencia para IA. Con la capacidad de cargar pesos de un modelo, recibir un historial de conversación y devolver una respuesta. además de tener medidas de seguridad en la cual requerirá de autenticación para cualquier acción o petición a su endpoint. contará además con niveles de usuarios, nivel usuario común y usuario administrador.

## Requerimientos
- crear el venv usando el administrador de versiones uv en lugar del env estandar de python. 
- usar fastapi.
- la primer base de datos sera sqlite.

## Primer tarea
- Crear el código main en [main.py](../main.py)
- crear las rutas para auth en [auth.py](../routes/auth.py)

- revisar el directorio creado en el proyecto y así decidir donde escribir los modulos y decidir que dirs pueden llegar a faltar o sobrar (si aplica)
